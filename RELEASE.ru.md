# RetroCity Open World — заметки релиза

## Состояние релиза

RetroCity поставляется как самостоятельная 2D-игра с видом сверху и сохраняет исходную структуру проекта:
карта, районная застройка, интерьеры, транспорт, NPC, миссии, экономика, розыск, сохранения и пользовательский интерфейс.

Релиз подготовлен для публикации в репозитории MiryoLove Retro Gaming.

## Новое в релизе

- Экономика переведена на рубли с символом `₽`.
- Добавлены сохранения формата v4 с проверкой обязательных данных.
- Старые форматы и повреждённые сохранения не загружаются повторно.
- Улучшена система розыска: разные уровни реакции полиции, свидетельские сообщения, задержание эскалации,
  последнее известное местоположение и поиск после потери обзора.
- Добавлены карманные кат-сцены для ключевых моментов кампании с анимацией камеры, ракурсами, субтитрами
  и возможностью пропуска.
- Сохранены сюжетная кампания, торговые заведения, гараж, автосалон, банк, больница, полиция,
  динамическое время суток и погодные переходы.
- Управляемые вертолёты сохраняют высоту, топливо, повреждения и состояние посадки.
- Недвижимость поддерживает покупку и пассивный доход.

## Запуск

### Windows

```bat
cd RetroCity
run.bat
```

или:

```bat
cd RetroCity
python -m http.server 8000
```

### Linux

```bash
cd RetroCity
./run.sh
```

или:

```bash
cd RetroCity
python3 -m http.server 8000
```

Откройте в браузере: `http://localhost:8000`.

## Сохранения

- Основной ключ браузерного хранения: `retrocity3d_save`.
- Резервный ключ сохраняется только при создании последующего сохранения.
- Формат прогресса проверяется перед загрузкой.
- Старые версии не считаются совместимыми и не импортируются.
- При первом запуске обновленной сборки старые ключи игрового прогресса очищаются.
- Настройки разработчика, исходники и игровые ресурсы не являются сохранениями и не удаляются.

## Проверка перед публикацией

Перед выпуском проверяются:

- запуск через локальный HTTP-сервер;
- загрузка главного меню и игрового мира;
- выбор персонажа и начало новой игры;
- создание и повторная загрузка сохранения v4;
- отклонение устаревшего или повреждённого сохранения;
- сохранение миссий, денег, транспорта, инвентаря, недвижимости и настроек;
- начало и пропуск кат-сцен;
- все шесть уровней розыска;
- задержание, больница и снятие розыска;
- отсутствие JavaScript-ошибок в Playwright;
- отсутствие ключей, паролей, приватных данных или временных сохранений в релизных файлах.

## Известные ограничения

- Полный распорядок всех NPC по расписанию «дом — работа — магазин — дом» реализован не полностью.
- Не для каждой из 50 миссий предусмотрена полностью уникальная ветка кат-сцены.
- Голосовой озвучки нет; используются субтитры и процедурные звуковые эффекты.
- Управление самолётами не является обязательной системой; самолёты используются как объекты аэропорта.
- Анимация пламени и накопление погодных явлений могут зависеть от производительности устройства.

## Содержимое репозитория

Основная папка игры: `RetroCity`.

Репозиторий не должен включать приватные сохранения браузера, временные файлы тестов или локальные резервные копии.
