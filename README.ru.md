## 🎮 Игры

### OMEGA STATION

**OMEGA STATION** — оригинальный ретро-шутер от первого лица, вдохновлённый классическими FPS 1990-х годов.

**Особенности:**

- Псевдо-3D-графика на основе Raycasting.
- Пиксельная визуальная стилистика.
- 3 сюжетных эпизода и 36 уровней с индивидуальными названиями.
- 36 детерминированных макропланов с прямоугольными картами размером от 53×55 до 81×79.
- 16 архитектурных генераторов с разными правилами построения: промышленные пролёты, технический ствол, исследовательские крылья, кольцевой коридор, лабиринт обслуживания, атриум с ответвлениями, грузовые проходы, пункты охраны, многокрылый комплекс, плотная сеть комнат, длинный комплекс, сеть зон, асимметричный кампус, радиальная реакторная, открытый двор и органический улей.
- 12 тематик окружения — производство, исследования, реактор, военный сектор, логистика, жилой сектор, обслуживание, связь, подземная инфраструктура, эксперименты, биологическая опасность и инфернальная зона. Тематика влияет на материалы стен, палитры пола/потолка и освещение.
- Три художественных набора эпизодов: Industrial Nightmare, Biohazard и Infernal Dimension; новые пиксельные материалы металла, органики, камня и решётчатых настилов.
- Секреты, ключ-карты, тематические мостовые/ступенчатые настилы и пары лифтовых площадок с действующим переносом между секторами. Высотная геометрия пока не поддерживается исходным одноэтажным raycasting-движком.
- 50 тем оформления окружения.
- 12 типов локаций.
- 15 видов оружия, включая бензопилу с контактной атакой и звуком двигателя.
- Противники, интерактивные предметы и система боеприпасов.
- Три уникальных босса, сохранение кампании, статистика уровня и выбор открытых уровней.
- Детерминированная генерация с воспроизводимыми seed-ами, альтернативными маршрутами, необязательными дверями с ключами, секретами, парами лифтовых площадок и расстановкой врагов.
- Ретро-HUD, 36 вариаций процедурного музыкального оформления, эпизодные фоновые звуки, звуковые сигналы врагов и пиксельные следы крови.
- Щадящий режим для более комфортной игры.

## 🚀 Запуск игры

Для запуска необходим Python 3.

**Windows:**

```bash
cd "OMEGA STATION"
python -m http.server 8000
```

**Linux:**

```bash
cd "OMEGA STATION"
python3 -m http.server 8000
```

Затем открой [http://localhost:8000](http://localhost:8000) в браузере.

Для остановки сервера нажми `Ctrl+C`.

### Проверка генерации уровней

При работающем сервере открой [http://localhost:8000/tools/level-validation.html](http://localhost:8000/tools/level-validation.html). Страница генерирует и отображает 100 карт с фиксированными seed-ами. В отчёт входят распределение размеров комнат, коридоры, узлы пересечений, тупики, циклический ранг графа, секреты, размеры карт, достижимость выхода с учётом ключей и доступность лифтовых площадок. Дополнительно создаются все 36 runtime-объектов `Level`.

Похожие карты сравниваются по нормализованной пространственной занятости (с учётом поворотов и отражений) и сигнатуре структуры графа; совпадением считается Jaccard similarity не ниже 0,94 при одинаковой сигнатуре. Проверенная партия из 100 карт дала 0 недостижимых выходов, отключённых областей и близких дубликатов. Все 36 кампанийных карт также прошли проверку ключей/выходов и создание runtime-уровней. Примеры: кольцевой коридор *The Beginning*, грузовые проходы *Research Laboratory* и лабиринт обслуживания *Maintenance Tunnels*.
