## 🎮 Игры

### OMEGA STATION

**OMEGA STATION** — оригинальный ретро-шутер от первого лица, вдохновлённый классическими FPS 1990-х годов.

**Особенности:**

- Псевдо-3D-графика на основе Raycasting.
- Пиксельная визуальная стилистика.
- 10 игровых эпизодов.
- 100 уровней.
- 50 тем оформления окружения.
- 12 типов локаций.
- 14 видов оружия.
- Противники, интерактивные предметы и система боеприпасов.
- Процедурная генерация карт на основе начального значения (seed).
- Ретро-интерфейс и звуковые эффекты.
- Щадящий режим для более комфортной игры.

## 🚀 Запуск игры

Для запуска необходим Python 3.

**Windows:**

```bash
cd "OMEGA STATION"
python -m http.server 8000
```

**Linux:**

```bash
cd "OMEGA STATION"
python3 -m http.server 8000
```

Затем открой [http://localhost:8000](http://localhost:8000) в браузере.

Для остановки сервера нажми `Ctrl+C`.
