## 🎮 RetroCity Open World

**RetroCity Open World** — 2D open-world проект с видом сверху.

**Основные возможности:**

- Большая карта с районами, дорогами, интерьерами и портовой/аэропортовой инфраструктурой.
- Пешеходы, трафик, полиция, блокпосты и шесть уровней розыска.
- Автомобили, мотоциклы, специальный транспорт и управляемые вертолёты.
- Экономика в рублях `₽`, магазины, банк, гараж, автосалон и недвижимость.
- Сюжетная кампания, дополнительные задания, сохранения и кинематографические кат-сцены.
- Динамическое время суток и погодные переходы.

## 🚀 Запуск

Для запуска нужен Python 3.

### Windows

```bat
cd RetroCity
run.bat
```

Или:

```bat
cd RetroCity
python -m http.server 8000
```

### Linux

```bash
cd RetroCity
./run.sh
```

Или:

```bash
cd RetroCity
python3 -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

Для остановки сервера нажмите `Ctrl+C`.
