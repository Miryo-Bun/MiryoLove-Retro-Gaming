**MiryoLove Retro Gaming** is an open-source gaming initiative by MiryoLove dedicated to retro-inspired games,
classic gameplay, and independent game development.

Our goal is to preserve the spirit of classic gaming and bring it into modern open-source projects.

## 🎮 RetroCity Open World

**RetroCity Open World** is a top-down 2D open-world project.

**Main features:**

- Large city map with districts, roads, interiors, port, and airport infrastructure.
- Pedestrians, traffic, police, checkpoints, and six wanted levels.
- Cars, motorcycles, special vehicles, and controllable helicopters.
- Ruble-based economy using `₽`, shops, bank, garage, dealership, and real estate.
- Story campaign, side activities, saves, and cinematic cutscenes.
- Dynamic time of day and weather transitions.

## 🚀 Running the Game

Python 3 is required.

### Windows

```bat
cd RetroCity
run.bat
```

Or:

```bat
cd RetroCity
python -m http.server 8000
```

### Linux

```bash
cd RetroCity
./run.sh
```

Or:

```bash
cd RetroCity
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

Press `Ctrl+C` to stop the server.
